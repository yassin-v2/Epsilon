## Features

- **RP2354A MCU** - 32bit dual core ARM Cortex-M33 MCU, with RISC-V cores and 2Mb of internal flash memory.
- **Very compact, XIAO SEEED inspired formfactor**.
- **4 ADC and 7 digital GPIO pins**.
- **5V and 3.3V output power pins**.
- Power indicator LED and addressable LED.
- **USB C** - for programming and power.
