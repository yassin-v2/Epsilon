# Epsilon
 A very compact, 4-layer devboard integrating the RP2354A MCU, named Epsilon. 


----

<img width="1723" height="892" alt="image" src="https://github.com/user-attachments/assets/f8fd7df8-7911-4904-b1f0-2386a428a323" />


## Features
- **RP2354A MCU** - 32bit dual core ARM Cortex-M33 MCU.
- **Very compact, XIAO SEEED inspired formfactor**
- **I2C and SPI** - on many pins.
- **5V and 3.3V power pins**.
- Power indicator LED and another addressable LED
- **USB C** - for programming and power.
